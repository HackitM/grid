GRID is a terminal-first macOS workspace with a Tron-inspired interface: a real terminal, a file browser, an app launcher, a widget deck and a web browser in one keyboard-driven window. **0.3.0 is the first published build** and includes everything below.

## Install
1. Download **GRID-0.3.0-macOS.zip**, unzip it, and move **GRID.app** to Applications.
2. This build isn't notarized by Apple yet, so macOS blocks it the first time. Open it once, then go to **System Settings › Privacy & Security** and click **Open Anyway** (you only need to do this once).
3. Optional: check the download against **GRID-0.3.0-macOS.zip.sha256** with `shasum -a 256 GRID-0.3.0-macOS.zip`.

**Requires macOS 15** (browser extensions need macOS 15.4). Built for Apple silicon.

## What's new: a recap of every update

### Embedded browser *(latest)*
- A full browser in the Web page (Safari's engine, WebKit) drawn in GRID's style: tabs, address bar with search, find, zoom and history. ⌘T, ⌘W, ⌘F, ⌘L, ⌘R and ⌘[ / ⌘] work on the browser while it's showing.
- **Reader view (⇧⌘R)** re-sets articles in GRID's monospaced layout with numbered links.
- **Site themes** give GitHub, Hacker News, MDN, Wikipedia and Stack Overflow GRID's colours and type, per site, one click back to the original, and they follow your GRID theme.
- **Ad blocking** with uBlock Origin's default filter lists through Safari's built-in content blocker (about 129,000 rules), plus a one-click "off for this site".
- **Browser extensions** (Chrome / Safari format, macOS 15.4+) install after a permission review; their buttons appear as GRID-style glyphs only when one is installed.
- Pages can't reach your terminal, files or apps; links to other apps need a click and a confirmation; downloads always ask first and are quarantined like Safari's.

### Widget platform, File Inspector and deck layouts
- **Build your own widgets**: a folder with a manifest and JavaScript. *New Widget…* creates one that reloads as you edit; *Install…* adds someone else's after you approve exactly what it can access. Widgets run in a locked-down helper process, are drawn with GRID's own components, and pause themselves if they use too much CPU or memory. Nine examples are included in the repository.
- **File Inspector widget**: see the exact quoted text a file will insert into the terminal, whether it's executable or downloaded from the internet, line counts, encoding and more, before you drag it in.
- **Side-by-side deck**: drag a widget by its title onto another card's edge to place it beside or below; great with the deck docked at the bottom.
- **Performance fix**: the System and Network widgets no longer spike CPU (about 40% down to about 1%).

### Dockable workspace, motion and folder tree
- Files, Terminal and the Widget Deck are panels you can close, reopen and re-dock by dragging their title bars to any edge; terminal panes and tabs drag the same way.
- Motion inspired by the films: panels trace themselves in, rows cascade, selectors slide, and drop targets scan (all respect Reduce Motion and can be turned off).
- Folders in Files expand in place as an indented tree.

### Milestone 2: split panes, file operations, widgets
- Split terminal panes in any direction (up to six per tab) with draggable dividers, tab renaming and a bell indicator.
- A themed find bar for the terminal (case, regex, whole word) and fully customizable keyboard shortcuts.
- File operations: new folder, rename, duplicate, copy, paste, move, Move to Trash, conflict handling and multi-step undo; multi-select, Quick Look and Open With.
- The widget deck (⌘J): Clock, System, Network, Storage, Power, Sessions, Pinned Apps, Git, Notes and Recent Files, all showing real measurements.
- Faster command-palette scrolling and a working grid backdrop.

### Reliability and safety fixes
- ⌘W never quits GRID by accident; closing a session or quitting cleans up running programs precisely.
- Opening a file that would run a program asks first; previews can't hang on special files.

### Milestone 1: the foundation
- A real terminal (login shell, tabs, working-directory tracking, busy and finished-job indicators) with safe, quoted file-path drops that never run anything.
- A file browser with breadcrumbs, history, sorting, filtering and search, an inspector with previews, and clear permission states.
- An app launcher with search, pins and recents; a command palette for everything.
- Three themes: Legacy (cyan), Ares (red) and ENCOM (amber); optional glow, motion and grid backdrop.

## Privacy
No accounts, telemetry or cloud services. Settings, history and browsing data stay on your Mac. The only network requests GRID makes on its own are downloading ad-blocking filter lists from their publishers (when ad blocking is on) and Safari's standard fraudulent-site check in the browser.

## Known limitations
- Not notarized yet (see Install).
- Some ads that uBlock Origin removes with page scripts (for example on YouTube) can't be blocked with Safari's engine.
- Extension popups show the extension's own design.
