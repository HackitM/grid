GRID 1.0.1 is a small update to [1.0.0](https://github.com/max-pasho/grid/releases/tag/v1.0.0). It fixes YouTube in GRID's browser, blocks YouTube's video ads, and turns site themes into packs that can improve without a new version of GRID. If you're on 1.0.0, replace GRID.app with this one; your settings, layout, widgets, browsing data and map regions carry over.

![YouTube in GRID's browser with the GRID site theme: squared chips and buttons, a monospace sidebar, and framed thumbnails with corner brackets and numbered panels](https://github.com/max-pasho/grid/blob/v1.0.1/docs/screenshots/youtube-theme.jpg?raw=true)

## Install
1. Download **GRID-1.0.1-macOS.zip**, unzip it, and move **GRID.app** to Applications (replace the old one if asked).
2. This build isn't notarized by Apple yet, so macOS blocks it the first time. Open it once, then go to **System Settings › Privacy & Security** and click **Open Anyway** (you only need to do this once).
3. Optional: check the download against **GRID-1.0.1-macOS.zip.sha256** with `shasum -a 256 GRID-1.0.1-macOS.zip`.

**Requires macOS 15** (browser extensions need macOS 15.4). Built for Apple silicon.

**On 1.0.0? Download this one by hand.** GRID's repository moved to github.com/max-pasho/grid, and 1.0.0's update check only trusts the old address, so **Settings › Updates** in 1.0.0 won't find this release. From 1.0.1 on, update checks use the new address again.

## Fixes
- **YouTube loads again** with ad blocking on. One filter in the lists was being widened into a block of YouTube's own scripts; GRID now skips a filter rather than widen it when it can't express the sites it names.
- **Site themes:** YouTube's search results no longer show empty thumbnail frames, and Google's results, answers and AI Overviews are easier to read (Google's own typeface for body text, brighter secondary text).

## YouTube without video ads
- **Pre-roll and mid-roll ads are gone** on YouTube. GRID now runs uBlock Origin's site-specific **scriptlet** rules, the ones that strip ads out of YouTube's player data, alongside Safari's content blocker.
- **Lists supply arguments, never code.** GRID ships its own implementations of about 25 common scriptlets. Scriptlets whose arguments are code, and generic ones meant for every site, are never run.
- **Your control:** turn it off in **Settings › Browser › Ad blocking** (**Run uBlock's site fixes**). It never runs on a site where you've turned blocking off.

## Site themes, updatable
- **Updates without a new GRID:** site themes are plain CSS packs. Turn on **Check GRID’s repository for new and improved themes daily** in **Settings › Browser › Site themes** to get improved themes from GRID's repository once a day; it's off by default.
- **Checked before use:** each downloaded theme must match its SHA-256 in the repository's index. It also mustn't load anything from the internet (no `@import`, no remote images or fonts), so a theme can't run code or send a page's contents anywhere.
- **Your own themes:** **New Theme…** starts a pack for the site you're on in a folder GRID watches. Your themes win over built-in and downloaded ones.
- **YouTube's new HUD look:**
  - A grid floor, a command-bar header and a monospace sidebar.
  - Framed thumbnails with corner brackets, scanlines, numbered panels and a scan sweep on hover.
  - A framed player labelled PLAYBACK // CHANNEL 01.
- **New themes:** **Reddit**, **DuckDuckGo** and **Twitch**.
- **GitHub's** homepage and marketing pages are themed too.

## Privacy
Unchanged by default: no accounts, telemetry or cloud services. The one new network request is the theme update check. It goes to raw.githubusercontent.com once a day, only if you turn it on, and sends no identifiers.

## Known limitations
- Not notarized yet (see Install).
- GRID runs uBlock's site-specific scriptlets but not its generic ones or HTML filtering, so a few ads uBlock Origin removes still get through. YouTube changes its ad delivery often; blocking there is only as current as the filter lists.
- Site themes follow each site's current design and can fall behind when a site changes. Theme updates can fix that without a new GRID.
